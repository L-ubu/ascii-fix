AI broke the table. This fixes it.

AI models love generating ASCII tables and boxes but consistently mess up alignment, padding, corners and widths. ascii-fix auto-detects and corrects all of it.

02What you get

◆ Column alignment

Every row's delimiters land at the same positions. Ragged right edges get squared up automatically.

◆ Padding repair

Cells get exactly one space of padding on each side, always. No more squashed or drifting content.

◆ Border width matching

Borders are regenerated to span the full width of the widest content — corners included.

◆ Style conversion

Flip a box between --style square, rounded, double and heavy borders in one pass.

◆ CJK & emoji aware

Fullwidth characters count as two columns, so CJK and emoji rows stop breaking the grid.

◆ Check mode

--check exits 1 when a file is broken — drop it in CI or a pre-commit hook and never ship crooked art.

03Usage

Pipe it, point it at a file, or let it watch.

CommandWhat it does
echo "broken" | npx ascii-fixFix from stdin
npx ascii-fix input.txtFix a file, print to stdout
npx ascii-fix --write input.txtFix in place
npx ascii-fix --style roundedConvert border style
npx ascii-fix --check input.txtDetect only — exit 1 if broken
npx ascii-fix --json input.txtMachine-readable report

04Why it exists

The decisions worth knowing about, written down.

LLMs can't count columns

Tokenizers don't see monospace grids, so every model eventually ships a table with a bent right edge. This is the deterministic cleanup pass.

Zero dependencies, zero ceremony

One package, npx-able, no config file. The fix should never be more annoying than the problem.

Prefer prevention?

ascii-fix-rules teaches your AI to generate correct ASCII art in the first place — npx ascii-fix-rules init.
